SECURITY FIRST

Protecting the platform is part of building the platform.

Security is considered across account access, application functionality, data handling and platform operations.

01

Our Security Approach

RicozStore follows a layered approach to application and platform security. We aim to reduce unnecessary access, protect sensitive information and continuously improve the security of the service.

A

Account Protection

Authentication and account controls help protect access to store management features.

P

Platform Protection

Application and infrastructure controls are used to help maintain a secure platform environment.

M

Monitoring

We work to identify unusual activity and address potential security issues affecting the platform.

I

Improvements

Security practices evolve as the platform, technology and threat landscape change.

02

Account Security

Store management features are intended to be available only to authenticated users. Users should protect their credentials and avoid sharing account access unnecessarily.

  • ✓ Use a strong and unique password
  • ✓ Keep account credentials private
  • ✓ Sign out from shared or public devices
  • ✓ Report suspicious account activity
03

Access Control

RicozStore separates public-facing information from authenticated store management features. This helps ensure that operational tools are accessed through the appropriate account flow.

PUBLIC Marketing pages
Accessible without an account
PROTECTED Store management
Requires authenticated access
04

Data Protection

We take reasonable measures to protect information processed through the platform. Access to business and account information should be limited to the functionality and permissions required for legitimate use.

✓
Protection through multiple layers.

Account authentication, access restrictions and application-level protections work together to reduce unnecessary exposure.

05

Application Security

Application security is considered throughout the development and maintenance of RicozStore. This includes protecting authenticated routes, validating user input and reducing opportunities for unauthorized access.

Secure Access

Protected dashboard functionality requires an authenticated session.

Input Validation

Application inputs are handled with validation and appropriate database operations.

Least Access

Store operations should only expose the information needed for the requested functionality.

Continuous Improvement

Security controls can be improved as new requirements and risks are identified.

06

Found a security concern?

If you believe you have identified a security issue affecting RicozStore, please contact our team with enough information for us to understand and investigate the concern.

RESPONSIBLE DISCLOSURE
